# HarmonyOS NEXT

A HarmonyOS NEXT–style phone and tablet simulator in one self-contained `index.html`. No build step, no dependencies, no API keys.

## What's inside
- **Home screen:** two pages with widgets (Tips, Health steps, weather), app icons and a dock.
- **Apps:** Phone dialer with call timer, Messages (chats with auto-replies), Browser, Camera (uses your webcam, shots go to Gallery), Gallery, Calendar, Clock with stopwatch, Files, Notepad (saved in your browser), Settings, Themes (wallpapers), Music (plays a tune), Health, App Gallery, Huawei Video.
- **Notifications:** swipe down from the top-left.
- **Control Panel:** swipe down from the top-right for toggles, brightness and volume.
- **Phone ⇄ Tablet:** the button in the top-right corner switches layouts.
- **Go home:** swipe up or tap the bottom bar. Swipe left/right to change pages.

Mouse drags work like swipes on desktop.

## Run locally
Open `index.html` in any modern browser, or serve the folder with any static server.
